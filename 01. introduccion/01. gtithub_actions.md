# GitHub Actions

GitHub Actions es una plataforma de automatización integrada en GitHub que permite ejecutar tareas automáticamente cuando sucede algo en un repositorio, cuando llega una hora determinada o cuando se solicita manualmente.

Se utiliza, por ejemplo, para:

- Ejecutar pruebas automáticamente.
- Validar código.
- Construir aplicaciones.
- Desplegar aplicaciones.
- Automatizar tareas relacionadas con un repositorio.

# 1. ¿Qué es un archivo YAML?

YAML significa **YAML Ain't Markup Language**.

Es un formato de serialización de datos que permite representar información de manera estructurada y legible para los humanos.

Se utiliza en diferentes herramientas para definir configuraciones, procesos y estructuras de datos.

En GitHub Actions, los workflows se definen mediante archivos YAML con extensión `.yml` o `.yaml`.

Ejemplo:

```yaml
name: Mi primer workflow

on: push

jobs:
  saludar:
    runs-on: ubuntu-latest
    steps:
      - name: Mostrar mensaje
        run: echo "Hola desde GitHub Actions"
```

## 1.1. ¿Por qué es importante la indentación en YAML?

A diferencia de otros lenguajes y formatos, YAML utiliza la indentación para representar la estructura y las relaciones entre los elementos.

La indentación determina qué elementos pertenecen a otros elementos.

Por ejemplo:

```yaml
jobs:
  saludar:
    runs-on: ubuntu-latest
    steps:
      - name: Mostrar mensaje
        run: echo "Hola"
```

La estructura es:

- `jobs` contiene los trabajos.
- `saludar` es un job dentro de `jobs`.
- `runs-on` y `steps` pertenecen al job `saludar`.
- `name` y `run` pertenecen a un step.

Si la indentación es incorrecta, GitHub Actions puede interpretar mal la estructura o rechazar el archivo.

### Reglas importantes de indentación

- Se utilizan espacios, no tabulaciones.
- Los elementos que pertenecen a otro elemento deben tener mayor indentación.
- Los elementos que pertenecen al mismo nivel deben tener la misma indentación.
- Las listas se representan utilizando `-`.

Ejemplo de una lista:

```yaml
steps:
  - name: Primer paso
    run: echo "Paso 1"

  - name: Segundo paso
    run: echo "Paso 2"
```

Aquí tenemos dos steps dentro de una lista.
